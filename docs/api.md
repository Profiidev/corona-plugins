# Writing corona plugins (plugin API 2)

A plugin extends corona with bar widgets, panels and a background service, written in JavaScript or TypeScript. Plugin API 2 runs on `corona_js`, built on rquickjs 0.14. Corona loads only API 2 plugins; a plugin without `api = 2` is refused with "written for plugin API 1, corona runs API 2". If you are porting an API 1 plugin, read [Appendix: porting from API 1](#appendix-porting-from-api-1).

This guide is the author's reference: the manifest, the three kinds of script, every module a plugin can import, and the limits it runs under. The exact types are always the generated ones: run `corona types <plugin dir>` to write `corona.d.ts` next to the manifest (loading the plugin does the same). It declares only the corona modules the manifest grants. It writes no `jsconfig.json`; add your own `tsconfig.json` or `jsconfig.json` if your editor needs one.

## 1. Anatomy of a plugin

A plugin is a directory with a `plugin.toml` and the scripts it names:

```
com.example.inbox/
├── plugin.toml      manifest
├── service.ts       optional background service
├── widget.ts        a bar widget view
├── panel.ts         a panel view
├── locales/app.yml  optional translations for corona/i18n
└── corona.d.ts      generated by `corona types`
```

Three kinds of script exist. Each is an ES module whose default export is the entry point:

| Kind    | Declared as        | Default export            | Purpose                                    |
| ------- | ------------------ | ------------------------- | ------------------------------------------ |
| Widget  | `[widgets.<name>]` | a `View` subclass         | A button or readout in a bar               |
| Panel   | `[panels.<name>]`  | a `View` subclass         | A window opened from a widget or by name   |
| Service | `service = "…"`    | `async function main(cx)` | Headless; runs while the plugin is enabled |

Scripts may import each other with relative paths. They cannot import anything outside the plugin directory. `.ts` and `.mts` load with their types stripped ([13](#13-runtimes-loading-and-hot-reload)).

A minimal widget:

```ts
import { type Context, type Element, View } from 'corona/kit';
import { Button } from 'corona/component';
import { getState } from 'corona/plugin';
import { isPanelOpen, togglePanel } from 'corona/surface';

export default class Widget extends View {
  render(_cx: Context): Element {
    const button = new Button('toggle')
      .label(`Inbox ${getState('count') ?? '–'}`)
      .size('small');
    return (isPanelOpen('main') ? button.primary() : button.ghost()).on_click(
      () => togglePanel('main')
    );
  }
}
```

## 2. The manifest (`plugin.toml`)

Unknown keys are an error. An editor can validate the file against the JSON schema; the first line of a manifest is conventionally `#:schema <path to plugin.schema.json>`.

```toml
id = "com.example.inbox"
name = "Inbox"
api = 2
version = "1.0.0"
description = "Unread mail in the bar"
service = "service.ts"

[widgets.count]
view = "widget.ts"
name = "Inbox"

[panels.main]
view = "panel.ts"
name = "Inbox"
width = 520
height = 640

[[settings]]
key = "server"
label = "Server"
type = "text"
default = ""

[capabilities]
corona = ["notifications"]
network = { hosts = ["${setting:server}"] }
```

| Key            | Type              | Meaning                                                                                                                            |
| -------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `id`           | string, required  | Reverse-DNS identity, e.g. `com.example.inbox`. Letters, digits, `.`, `_`, `-`. Namespaces widgets, panels, storage and approvals. |
| `name`         | string, required  | Shown in menus and the permission prompt.                                                                                          |
| `api`          | integer, required | Must be `2`. Left out it counts as `1` and the plugin is refused.                                                                  |
| `version`      | string            | Semantic version.                                                                                                                  |
| `description`  | string            | One line, shown in the settings app.                                                                                               |
| `widgets`      | table             | Bar widgets by name. A bar lists one as `<id>:<name>` (`widget_type = "com.example.inbox:count"`).                                 |
| `panels`       | table             | Panels by name, opened as `<id>:<name>`.                                                                                           |
| `service`      | path              | Script of the background service.                                                                                                  |
| `commands`     | table             | Launcher commands by name, searched as `<id>:<name>` and answered by the service ([`launcher`](#launcher)).                        |
| `settings`     | array of tables   | User-changeable settings ([3](#3-settings)).                                                                                       |
| `capabilities` | table             | What the plugin may do ([4](#4-capabilities)).                                                                                     |

- **Widget** (`[widgets.<name>]`): `view` (script path, required), `name` (label in the bar editor; the key when unset).
- **Panel** (`[panels.<name>]`): `view`, `name`, `width` (default 400), `height` (default 500). Width and height must be above 0 and at most 8192.
- **Command** (`[commands.<name>]`, needs `service` and `corona = ["launcher"]`): `title` (required), `subtitle`, `icon` (a bundled icon's kebab-case name, like `folder-open`), `keywords`, `section` (`favorites`, `recent`, `suggestions`, `applications`, `commands` (default), `results`, `fallback`), `args` (`[{ name, kind = "text" | "number" | "level" | "duration" | "choice", choices, optional }]`) and `scope = { prefix, label, placeholder }`, which searches the command's list page after typing `prefix` and a space. A prefix belongs to one command.
- Widget, panel and command keys are flat names (letters, digits, `.`, `_`, `-`).
- Every script path must be a file inside the plugin directory.

## 3. Settings

Each `[[settings]]` entry has `key`, `label`, optional `description` and a `type`. Keys are unique. A default must be a value the setting accepts. Users change settings in the settings app; values live in the shell config under `[plugin_settings."<id>"]`. A configured value that does not fit falls back to the default.

| `type`   | Fields                                                | Value                                                                                                           |
| -------- | ----------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `toggle` | `default: bool`                                       | `boolean`                                                                                                       |
| `text`   | `default: string`, `placeholder?`                     | `string`                                                                                                        |
| `number` | `default`, `min?`, `max?`, `step?`                    | `number`; bounds finite, `step > 0`, `min <= max`                                                               |
| `slider` | `default`, `min`, `max`, `step`                       | `number`; `min < max`, `step > 0`                                                                               |
| `select` | `default`, `options = [{ value, label }]`, `dynamic?` | the chosen `value`; with `dynamic = true` the service supplies the options at runtime and any string is allowed |
| `list`   | `default: string[]`                                   | `string[]`, rows added and removed one by one                                                                   |
| `secret` | `placeholder?`                                        | a masked input stored in the keyring, never in the config                                                       |

A `secret` setting requires `corona = ["secrets"]`; read it with `get(key)` from `corona/secrets`.

Read settings from `corona/settings` ([9](#9-modules-every-plugin-has)). A plugin can change a setting with `set`, except one a `${setting:<key>}` host grant reads.

## 4. Capabilities

Everything beyond pure computation is granted in `[capabilities]`. The user approves the grant when the plugin is enabled. A denied call throws (sync) or rejects (async) with a `TypeError`, for example "filesystem read is not granted; declare capabilities.fs.read in the manifest".

```toml
[capabilities]
corona = ["notifications", "power"]
storage = true
fs = { read = [
  "${pluginDir}",
  "${dataDir}"
], write = [
  "${dataDir}"
], execute = [
  "sh"
] }
network = { hosts = [
  "api.example.com"
], unix = [
  "/run/tailscale/tailscaled.sock"
] }
clipboard = { write = true }
process = { env = ["PATH", "HOME"] }
dbus = { session = ["org.kde.kdeconnect"] }
printing = { print = true }
```

| Key                 | Fields                                                              | Grants                                                                                                                                                                                                                    |
| ------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `corona`            | list of module names                                                | The `corona/<name>` modules in [10](#10-modules-granted-by-capabilitiescorona). An unknown name fails the load: "plugin `<id>` is granted unknown module `<name>`".                                                       |
| `storage`           | bool, **default `true`**                                            | `localStorage`. The one grant given by default; set `false` to withdraw it.                                                                                                                                               |
| `fs.read`           | paths                                                               | Directories `fs/promises` may read, and `image(path)` / `Avatar.src` may show.                                                                                                                                            |
| `fs.write`          | paths                                                               | Directories that may be written: absolute, or under `${dataDir}`. Never the plugin directory, other plugins, corona's state or config, home dotfiles, or places that run at login. Such a root is dropped with a warning. |
| `fs.execute`        | list of commands, or `"*"`                                          | Commands `process.run` and `spawn` may start. Only the string `"*"` means all; any other string is an error.                                                                                                              |
| `network.hosts`     | hosts                                                               | Hosts `fetch` and `websocket` may reach (public addresses only).                                                                                                                                                          |
| `network.lan_hosts` | hosts                                                               | Like `hosts`, but the name may also resolve to the local network. Loopback and link-local stay closed.                                                                                                                    |
| `network.http`      | list of `{ host, methods, scheme?, port?, paths?, path_prefixes? }` | HTTP requests limited by host, method and path. `scheme` defaults to `https`.                                                                                                                                             |
| `network.unix`      | socket paths                                                        | Unix sockets for `net.connect({ path })` and `fetch(..., { unix })`, by exact path. Never a socket the plugin could plant, nor the session's buses, agents or compositor.                                                 |
| `clipboard`         | `read`, `write`                                                     | Clipboard access from views.                                                                                                                                                                                              |
| `process`           | `exit`, `env`                                                       | `exit` allows `process.exit()`. `env` lists the host variables passed to children, and the only names a child's `env` option may set. Children otherwise get an empty environment. Variables like `LD_*` are refused. `HOME`, `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, `XDG_CACHE_HOME` and `XDG_STATE_HOME` can be listed too, but pass the user's value only: a child's `env` option cannot set them.     |
| `printing`          | `print`, `manage`                                                   | Beyond listing: `print` allows `printFile`; `manage` allows scanning, adding and pausing printers and canceling jobs.                                                                                                     |
| `dbus`              | `session`, `system` (bus names)                                     | The bus names `corona/dbus` may call, read and receive signals from. The module exists only with this table.                                                                                                              |

**Placeholders.** `${pluginDir}` and `${dataDir}` work in `fs` and `network.unix` paths; any other `${…}` is an error. `${setting:<key>}` works in `network.hosts`, `lan_hosts` and `http[].host`: it expands to the host of text setting `<key>` (a URL or a bare host with optional port), and grants nothing while the setting is empty. The key must name a `text` setting. Only values the user set count, never the plugin's defaults.

**Approval.** The grant a user approved is stored, so a manifest that asks for more must be approved again.

## 5. Views: widgets and panels

A view is a class extending `View` from `corona/kit`:

```ts
abstract class View {
  constructor(props?: Props);
  init?(props: Props | undefined, cx: Context): void; // once
  update?(props: Props | undefined): void; // parent passed new props
  abstract render(cx: Context): Element | Entity | string;
}
```

`render` runs whenever the view is notified, and again when a `Signal` it read during `render` changes. Do not keep an `Element` on the instance. Call `cx.notify()` after changing instance state; it throws inside `render`.

### Context (`cx`)

| Member                                              | Meaning                                                                                                                                                                                    |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `notify(target?)`                                   | Render again (the view, or the retained child `target`).                                                                                                                                   |
| `new(Class, props?)`                                | Create a retained child view (`Entity`), not inside `render`. Use `entity.set_props(props)` to update it and `entity.release()` to free it.                                                |
| `spawn(body)`                                       | Calls `body(cx)` and returns what it returns (the promise, for an async body). Not cancelable; check a flag in the body to stop it. A rejected body is reported as an unhandled rejection. |
| `sleep(ms?)`                                        | Promise resolving after `ms`.                                                                                                                                                              |
| `timer.after(ms, cb)`, `timer.every(ms, cb)`        | Return a `TimerHandle` with `cancel()`.                                                                                                                                                    |
| `focus_handle()`                                    | A `FocusHandle`; make it in `init` or a handler, never in `render`.                                                                                                                        |
| `bind_keys(bindings)`                               | Install key bindings (`{ keystroke, action, context? }`), all or none; handle with `.on_action`. They end with the runtime. `::` is reserved in action names.                              |
| `stop_propagation()`, `propagate()`                 | Stop or undo stopping an event reaching outer handlers.                                                                                                                                    |
| `phase()`                                           | `"render" \| "event" \| "task"`.                                                                                                                                                           |
| `theme()`                                           | The theme's semantic tokens.                                                                                                                                                               |
| `open_url(url)`                                     | Open an absolute http(s) URL.                                                                                                                                                              |
| `read_from_clipboard()`, `write_to_clipboard(text)` | Need the `clipboard` grant.                                                                                                                                                                |

### Timers and async work

```ts
init(_props, cx) {
  this.t = cx.timer.every(1000, (cx) => { this.n++; cx.notify(); });
  cx.spawn(async (cx) => {
    this.data = await (await fetch("https://api.example.com/x")).json();
    cx.notify();
  });
}
```

### The `window` global

The global `window` is `import("corona/kit").Window`. Overlays open from handlers, not from `render`.

- **Dialogs:** `open_dialog(content, options?)`, `close_dialog()`, `close_all_dialogs()`, `has_active_dialog()`. `content` is a function re-run on every redraw.
- **Sheets:** `open_sheet(content)`, `open_sheet_at("top" | "bottom" | "left" | "right", content)`, `close_sheet()`, `has_active_sheet()`.
- **Toasts:** `push_toast({ title, description?, level?, timeout?, id? })` returns the id; `remove_toast(id)`, `clear_toasts()`. A toast hides after 5 s unless `timeout: null`.
- **State and metrics:** `bounds()`, `viewport_size()`, `mouse_position()`, `appearance()` (`"light" | "dark"`), `rem_size()`, `line_height()`, `is_window_active()`, `is_fullscreen()`, `is_maximized()`, `set_rem_size(n)`.
- **Actions and focus:** `dispatch_action(action)`, `focus_next()`, `focus_prev()`.
- **Window control:** `activate_window()`, `minimize_window()`, `zoom_window()`, `toggle_fullscreen()`, `refresh()`.
- **Drawing:** `paint_path(path, fill)` returns a canvas element. Build paths with `PathBuilder.fill()` / `.stroke(width)`; coordinates are numbers.

Use the globals `localStorage`, `sessionStorage` and `fetch` directly, not `window.…`.

### Surface and panels

`corona/surface` ([9](#9-modules-every-plugin-has)) opens and closes the plugin's panels from a widget, and tells a widget where it is. State shared between views goes through `getState` / `setState` from `corona/plugin`, which re-renders every view that read the key.

## 6. Elements and components

Views return `Element`s built with host functions. The builder style mirrors gpui: `div().flex().gap("md").child(...)`. A typo in a method name throws at runtime and fails type checking.

- **`corona/kit`** exports the core: `div()`, `svg(path)`, `image(source)`, `list(...)`, `uniform_list(...)`, `View`, `Context`, `Window`, event types (`ClickEvent`, `MouseButtonEvent`, `MouseMoveEvent`, `ScrollWheelEvent`, `KeyEvent`, `ModifiersChangedEvent`), geometry (`Point`, `Size`, `Bounds`), `Color`, `Length`, `DefiniteLength`, `ColorToken`, `PathBuilder`, `Background`, `ScrollHandle`, `FocusHandle`, `Entity`, `KeyBinding`.
- **`corona/base`** has layout helpers (`h_flex()`, `v_flex()`), theme access (`Theme`, `set_theme`), unstyled primitives (`@base` kinds) and docking (`dock_area`, `DockArea`, `DockGroup`, …).
- **`corona/component`** has the styled components. Each constructor works as `new X(id)` or `X.new(id)` and returns an `Element`.
- **`corona/fps`** has the frame-rate overlay: `fps_monitor()`, `show_fps_monitor(options?)`, `hide_fps_monitor()`, `fps_monitor_visible()`.

Component families in `corona/component`:

| Family              | Components                                                                                                                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Buttons and toggles | `Button`, `Link`, `Toggle`, `ToggleGroup`, `Checkbox`, `Switch`, `Radio`, `RadioGroup`, `HorizontalRadioGroup`, `Clipboard`, `Rating`                                                      |
| Inputs              | `Input`, `NumberInput`, `Textarea`, `OtpInput`, `Slider`, `ColorPicker`, `DatePicker`, `TimeField`, `Select`, `Combobox`, `InputGroup*`, `Field`, `Form`, `VForm`, `HForm`, `Label`, `Kbd` |
| Overlays            | `Popover`, `HoverCard`, `Tooltip`, `Dialog`, `AlertDialog`, `Sheet`, `Notification`                                                                                                        |
| Feedback            | `Alert`, `InfoAlert`, `SuccessAlert`, `WarningAlert`, `ErrorAlert`, `Badge`, `Tag`, `Skeleton`, `Spinner`, `Progress`, `Empty*`                                                            |
| Display             | `Icon`, `Image`, `Avatar`, `DescriptionList`, `Text`, `Calendar`, `Carousel*`                                                                                                              |
| Data                | `List`, `DataTable`, `Tree`, `TreeItem`, `Table*`, `BarChart`, `LineChart`, `AreaChart`, `PieChart`, `RadarChart`                                                                          |
| Chat and editing    | `Attachment`, `Bubble`, `Marker`, `Message`, `ShimmerText`, `Editor`, `Diff`                                                                                                               |
| Settings and forms  | `Settings`, `SettingPage`, `SettingGroup`, `SettingItem`, `Questionnaire*`                                                                                                                 |

State objects `InputState`, `TextareaState`, `SliderState` and `OtpState` come from `corona/base` and have `.new({ … })`.

### One `Element` type

There is one `Element` interface carrying every element and component method. Methods are typed per kind with `this` constraints, so the type checker rejects a method on the wrong kind. At runtime, calling a method on the wrong kind throws.

### Rules worth knowing

- `children(...)` takes an array. Spread any other iterable first: `children([...set])`.
- `id(string | number)` names an element. `list(id, …)` and `uniform_list(id, …)` take a string id.
- `on_item_click` works only on `v_virtual_list` / `h_virtual_list`.
- `Command`'s `on_select` and `on_confirm` receive `({ section, row }, cx)`.
- Charts take `rows[]` or `() => rows[]`. `DataTable` and `List` take an array or `() => rows`.
- `List`'s `render_row` must return an element, an entity or a string (not `null`).
- `Select` takes `.value(id)`. Set it on every render to make the `Select` controlled.
- Controlled components (`Checkbox`, `Switch`, `Select`, …) take their state in (`checked(..)`, `value(..)`) and report changes out (`on_change(..)`); update your state and call `cx.notify()`.
- Event positions are window-relative; element bounds are not reported.
- `AvatarImage(source)` takes a path string only.
- `PathBuilder` coordinates are plain numbers.

### Images and SVGs

- `image(path)` with a **relative** path does not resolve against the plugin directory. Pass an absolute path inside an `fs.read` root, or pass bytes (`image(await readFile(path))`). The plugin has no API for its own absolute path (`import.meta.url` is not set), so keep the path in a setting, or build or fetch the bytes.
- `svg(path)` with a relative path loads from corona's built-in icon set. Only absolute paths read files.
- `image(url)` is refused. Fetch the bytes instead.

## 7. The service

A service is a headless script that runs while the plugin is enabled. It answers calls from views and from the command line.

```ts
import { onCall, reply, fail, setState } from 'corona/plugin';
import type { Context } from 'corona/kit';

export default async function main(cx: Context) {
  onCall((call) => {
    if (call.method === 'ping') reply(call.id, 'pong');
    else fail(call.id, `unknown method ${call.method}`);
  });
  cx.timer.every(60_000, async () => setState('count', await unread()));
}
```

- `main(cx)` may be async. The service's `cx` is a small plain object with only `sleep(ms)` and `timer.after` / `timer.every`. `cx.spawn`, `open_url`, the clipboard and the other view members are not available; call async functions directly (`void loop(cx)`).
- A view calls the service with `call(method, args?)` from `corona/plugin`. It resolves to the service's `reply`, rejects on `fail`, when no service runs, or after 30 seconds.
- From a shell: `corona ipc plugin <id> <method> [args]`. `args` is parsed as JSON, else passed as a string. The answer is printed.
- `onCall` queues: calls made before the service registers are kept, none are lost.
- The service is restarted when a script file changes.

## 8. Signals, events and errors

### Signals

A read in a corona module is `export const x: Signal<T>`:

```ts
interface Signal<T> {
  (): T;
  subscribe(cb: (value: T) => void): () => void;
}
```

- `x()` returns the current value. In `render`, a changing signal renders the view again.
- `x.subscribe(cb)` also works in services. It calls `cb` on every change, not at once with the current value, and returns the function that stops it.

```ts
import { activeWorkspace } from 'corona/compositor';
const stop = activeWorkspace.subscribe((ws) => console.log(ws));
```

### Event callbacks

Events are callbacks registered with `onX(cb)`, which return an unsubscribe function: `onCall`, `onAction`, `onChange`, `onSleep`, `onRedirect` and `dbus.subscribe`.

Register before the event can happen. Except `onCall`, events are not buffered for a plugin that is not listening. `onRedirect` throws at once for an unknown or already-used id. At most 32 dbus subscriptions per load.

### Errors

Host functions that can fail **throw** (sync) or **reject** (async) with a JS `Error` carrying the message. Nothing returns `T | Error`.

```ts
try {
  await setVolume(id, 0.5);
} catch (e) {
  console.warn(e.message);
}
```

Unhandled rejections are logged.

### Shared types

`Value` is the JSON type `null | boolean | number | string | Value[] | { [key: string]: Value }`. It is declared in each module that uses it (`dbus`, `i18n`, `plugin`, `surface`). Optional fields are typed `field?: T | null`.

## 9. Modules every plugin has

These need no `capabilities.corona` entry.

### `corona/plugin`

| Export                                | Meaning                                                                                 |
| ------------------------------------- | --------------------------------------------------------------------------------------- |
| `getState(key): Value`                | Shared state of the plugin; `null` when unset. Reading in `render` subscribes the view. |
| `setState(key, value)`                | Sets state for all views of the plugin; `null` removes it.                              |
| `call(method, args?): Promise<Value>` | Views only. Calls the service.                                                          |
| `onCall(cb): () => void`              | Service only. `cb(call)` with `Call = { id, method, args }`.                            |
| `reply(id, value)`                    | Service only. Answers call `id`. Throws for an unknown id.                              |
| `fail(id, message)`                   | Service only. Answers with an error.                                                    |

### `corona/surface`

| Export                       | Meaning                                                                                                              |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `panels(): string[]`         | Names of the plugin's panels.                                                                                        |
| `togglePanel(name)`          | Open `name` at this widget (when called from one), or close it if open there.                                        |
| `openPanel(name)`            | Open `name`; an open one stays open.                                                                                 |
| `closePanel(name)`           | Close `name` if open.                                                                                                |
| `isPanelOpen(name): boolean` | Open or opening. A view that asks renders again as it opens and closes.                                              |
| `options(): Value \| null`   | This widget's options from the bar config; `null` in a panel or service, or when none.                               |
| `bar(): Bar \| null`         | `{ side: "top" \| "bottom" \| "left" \| "right", vertical, bare }` for the bar the widget is in; `null` outside one. |

### `corona/settings`

| Export                     | Meaning                                                                                                                       |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `get(key)`                 | Value of setting `key`; the default when the user set none. Typed from the manifest.                                          |
| `all()`                    | Every setting by key.                                                                                                         |
| `set(key, value)`          | Change a setting in the config, as the settings app would. Throws for a setting a host grant reads.                           |
| `setOptions(key, options)` | Replace the choices of a `dynamic` select: `{ value, label }[]`. Held in memory; set them again when the service starts.      |
| `onChange(cb): () => void` | `cb(change)` for each change: `{ key, value }`, or `{ key, secret: true }` for a stored or removed secret, without its value. |

### `corona/i18n`

| Export                  | Meaning                                                                                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `language(): string`    | The shell's language, e.g. `de` or `pt-BR`.                                                                                                                             |
| `t(key, vars?): string` | Translate `key` (`a.b` for nested keys) in the shell language, then the prefix (`pt`), then English; the key itself when missing. `%{name}` is replaced by `vars.name`. |

Translations are `locales/*.yml` in the plugin directory, in the format of the shell's own locales:

```yaml
_version: 2
widget:
  label:
    en: 'Inbox %{count}'
    de: 'Posteingang %{count}'
```

### `corona/dbus`

Present only with a `capabilities.dbus` table. Calls, property access and signals are limited to the granted bus names.

| Export                                                        | Meaning                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `call({ bus, dest, path, iface, method, args?, signature? })` | Call a method. Resolves to `null` without return values, the value with one, an array with more. A `v` argument takes the JSON type; `{ $type: "u", value: 3 }` sets it.                                                                                  |
| `getProperty({ bus, dest, path, iface, name })`               | Read a property.                                                                                                                                                                                                                                          |
| `getAll({ bus, dest, path, iface })`                          | Every property by name.                                                                                                                                                                                                                                   |
| `setProperty({ …, value, signature? })`                       | Write a property.                                                                                                                                                                                                                                         |
| `subscribe(rule, cb): Promise<() => void>`                    | `cb(signal)` for each signal matching `Rule = { bus, sender, path?, pathNamespace?, iface?, member?, arg0? }`. `sender` must be granted, or be `org.freedesktop.DBus` with member `NameOwnerChanged` and a granted `arg0`. Resolves to the stop function. |
| `nameHasOwner(bus, name)`                                     | Whether a granted name is on the bus.                                                                                                                                                                                                                     |

`bus` is `"session"` or `"system"`. Corona owns `org.freedesktop.Notifications`; send notifications through `corona/notifications`. The module's signal payload type is named `Signal`, shadowing the global `Signal<T>` inside the module only.

## 10. Modules granted by `capabilities.corona`

Add the module name to `corona = [...]`. Every `Signal` below is read with `x()` or `x.subscribe(cb)`; every `Promise`-returning function rejects on failure, and the sync functions listed throw.

### `auth`

- `fingerprint(): Promise<boolean>`: waits for one scan; `false` when the finger did not match. After a few failures attempts fail fast for a while.

### `bluetooth`

- Signals: `adapter` (`Adapter | null`), `listDevices` (`Device[]`), `pairingRequest` (`PairingRequest | null`).
- `answerPairing(accept, code?)`, `setPowered(on)`, `setDiscoverable(on)`, `startDiscovery()`, `stopDiscovery()`, `connect(address)`, `disconnect(address)`, `pair(address)`, `forget(address)`.

### `brightness`

- Signals: `listDisplays` (`Display[]`), `nightlight` (`Nightlight`).
- `setBrightness(id, value)`, `setNightlight(on)` (sync), `setNightlightTemperature(kelvin): number` (sync, clamps 1000–6500, returns what was set), `ddcutil(): Ddcutil`.

### `compositor`

- Signals: `listWorkspaces`, `activeWorkspace`, `listMonitors`, `activeMonitor`, `listWindows`, `activeWindow` (`Window | null`), `keyboardLayout` (`string | null`).
- `focusWorkspace(workspace)` (sync, by id or name).

### `compositor_control`

- `focusWindow(address)`, `closeWindow(address)`, `cursorPosition(): Position` (all sync).

### `desktop`

- `openPath(path)` opens a readable file in the default app; `openUri(uri)` opens `https:`, `mailto:` and the like (both sync).
- `listenRedirect(options?): Listening` listens once on `127.0.0.1` for an OAuth redirect (`timeoutMs` default 5 minutes, at most 10). Returns `{ id, port, redirectUri }`.
- `onRedirect(id, cb): () => void`: `cb` runs once with a `Redirect` (`{ path, query }`) or `{ message }` on timeout or failure.

### `idle`

- Signals: `stayAwake`, `inhibited`. `setStayAwake(on)`, `stayAwakeFor(minutes)` (sync).

### `launcher`

Commands in the launcher: declare them in `[commands.<name>]` ([2](#2-the-manifest-plugintoml)), answer them in the service. Settings lists them like the built-in ones, so the user can give them an alias, a favorite or turn them off. A command is shown while the plugin runs; running one when the service is down shows an error. `onRun` and the pages work in the service only, and need `corona = ["launcher"]`.

#### Declaring commands

```toml
id = "com.example.projects"
name = "Projects"
api = 2
service = "service.ts"

[capabilities]
corona = ["launcher", "desktop"] # `desktop` for `openPath` below

[commands.recent]
title = "Recent Projects"
subtitle = "Open a project"
icon = "folder"                  # a bundled icon's kebab-case name
keywords = ["zed", "code"]       # found by these, not shown
section = "suggestions"          # where it lands in the root list
scope = { prefix = "rp", label = "Projects", placeholder = "Search projects" }

[commands.note]
title = "New Note"
icon = "pencil"
args = [
  { name = "text", kind = "text", optional = true },
  { name = "tag", kind = "choice", choices = ["work", "home"], optional = true }
]
```

`scope` makes `rp ` (the prefix and a space) search only the command's list page; typing it runs the command's handler and shows the list it pushes. `kind` of an argument is `text` (the last one takes the rest of the input), `number`, `level` (`65`, `65%`), `duration` (`5m`, `1h30m`) or `choice`.

#### `onRun(name, handler)`

`handler(args)` runs when the user picks the command. `args` holds the typed arguments in manifest order, `null` for a skipped optional one. It may be `async`. What it returns is what the launcher does next: one key of the table below (two keys are an error), or nothing, which closes it.

```ts
import { onRun, form } from 'corona/launcher';

export default async function main() {
  onRun('note', (args) => {
    const [text, tag] = args; // string | number | null each
    if (text) {
      save(text, tag ?? 'home');
      return { hud: { text: 'Saved', icon: 'check' } }; // closes, shows a pill
    }
    return { push: noteForm() }; // nothing typed: ask
  });
}
```

| Reply                                          | Effect                                                                 |
| ---------------------------------------------- | ---------------------------------------------------------------------- |
| nothing                                        | Closes the launcher.                                                   |
| `{ push: page }`                               | Shows a page you made with `list`, `form` or `detail`.                 |
| `{ pop: true }`                                | Back to the previous page.                                             |
| `{ keepOpen: true }`                           | Stays open and refreshes.                                              |
| `{ toast: { title, message?, kind? } }`        | Stays open with a toast; `kind` is `success` (default), `failure` or `progress`. |
| `{ copy: { text } }`, `{ copy: { image, mime? } }` | Copies; `image` is base64, `mime` defaults to `image/png`.         |
| `{ paste: ... }`                               | As `copy`, then closes, refocuses the previous window and pastes.      |
| `{ hud: { text, icon? } }`                     | Closes and shows a pill.                                               |

A throw or a rejected promise shows an error toast. A handler has 30 seconds.

```ts
onRun('sync', async () => {
  try {
    await sync();
  } catch (e) {
    return { toast: { title: 'Sync failed', message: String(e), kind: 'failure' } };
  }
  return { toast: { title: 'Synced' } }; // stays open
});
```

#### Lists: `list(spec)`

A list page of rows. The launcher filters the rows by what is typed (title, subtitle and keywords).

```ts
import { onRun, list } from 'corona/launcher';
import { openPath } from 'corona/desktop';

onRun('recent', async () => {
  const projects = await loadProjects();
  return {
    push: list({
      title: 'Recent Projects', // the breadcrumb
      placeholder: 'Search projects',
      preview: true, // a preview pane, toggled with Ctrl+P
      empty: 'No projects', // shown when nothing matches
      rows: projects.map((p) => ({
        id: p.path, // stable across updates
        title: p.name,
        subtitle: p.path,
        keywords: [p.lang],
        icon: { name: 'folder' },
        accessories: [{ tag: { text: p.lang, tone: 'ok' } }, { text: p.when }],
        detail: {
          code: p.readme,
          metadata: [['Path', p.path], ['Opened', p.when]],
          tags: [[p.lang, null]]
        },
        actions: [
          // the first action runs on Enter, the rest are in the action panel
          { title: 'Open', run: () => { openPath(p.path); return { hud: { text: `Opened ${p.name}` } }; } },
          { title: 'Copy path', shortcut: 'ctrl-c', run: () => ({ copy: { text: p.path } }) },
          {
            title: 'Remove',
            destructive: true,
            confirm: { title: 'Remove?', message: p.path, button: 'Remove', skippable: true },
            keepOpen: true, // stays open after running
            run: async () => {
              await removeProject(p.path);
              return { toast: { title: 'Removed' } };
            }
          }
        ]
      }))
    })
  };
});
```

- Rows: `id`, `title`, `subtitle`, `keywords`, `icon`, `accessories`, `detail` and `actions`.
- Accessories: `{ tag: { text, tone? } }` (`tone` is `ok`, `off`, `warn` or `err`), `{ text }`, `{ icon: name }` and `{ progress: 0..1 }`.
- `detail` (the preview pane): one of `text`, `code` or `image` (a file in the plugin directory), plus `metadata: [key, value][]` and `tags: [text, tone | null][]`.
- Actions: `title`, `run`, `icon`, `shortcut`, `destructive`, `keepOpen` and `confirm`. `run` may return a reply like `onRun`'s.
- `query` sets the text the page opens with.

#### Updating a list

The handle `list` returns changes the page later. It outlives the handler, so keep it in the service.

```ts
let page: ReturnType<typeof list> | undefined;

onRun('inbox', async () => {
  page = list({ title: 'Inbox', rows: toRows(await fetchInbox()) });
  return { push: page };
});

// a timer or event of the service
async function refresh() {
  page?.setLoading(true); // the loading bar
  page?.setRows(toRows(await fetchInbox())); // replaces the rows, ends loading
}

// when the page is not needed any more; frees its rows' handlers
page?.close();
```

Setting rows frees the old rows' action handlers, so call `setRows` rather than building a new page. Closing is optional: a restart of the service empties every page.

#### Searching in the plugin: `onQuery`

By default the launcher filters the rows. For a large or remote set, answer each typed query yourself with `onQuery`; the launcher stops filtering and shows what you return. An answer to a query the user has since changed is dropped.

```ts
onRun('search', () => {
  const page = list({ title: 'Search', placeholder: 'Type to search' });
  page.onQuery(async (query) => {
    const hits = await api.search(query); // may take a while: the page shows loading
    return hits.map((h) => ({
      id: h.id,
      title: h.title,
      actions: [{ title: 'Open', run: () => openPath(h.path) }]
    }));
  });
  return { push: page };
});
```

## 11. Standard library

### Globals

`console`, `process`, `Buffer`, `URL`, `URLSearchParams`, `fetch`, `localStorage`, `sessionStorage`, `setTimeout`, `setInterval`, `clearTimeout`, `clearInterval`, `queueMicrotask`.

Not available: the global `crypto`, `atob`, `btoa`. Use `randomUUID` / `randomBytes` from `"crypto"` and `Buffer.from(s, "base64")` / `buf.toString("base64")`.

### `fetch(url, options?)`

Options: `method` (GET), `headers`, `body`, `timeout` (ms, 1–300000, default 30000, covers redirects and reading the body unless streaming), `stream`, `unix`. Unknown options throw (`tls` is not supported). The host and path must be granted in `capabilities.network`; every redirect is authorized again, at most 10. Bodies are at most 8 MiB unless streamed. `Host`, `Origin`, `Content-Length` and similar headers are refused.

- Returns `FetchResponse`: `status`, `ok`, `url`, `headers` (lowercase), `text()`, `json()`, `arrayBuffer()`.
- With `{ stream: true }` returns `FetchStream`: `status`, `ok`, `url`, `headers`, `read(): Promise<Uint8Array | null>`, `close()`. A stream has no read timeout or size limit.
- `{ unix: "/path/to.sock" }` sends HTTP/1.1 over a socket granted in `network.unix`. Redirects are not followed.

### Modules

| Module        | Exports                                                                                                                                                                                                                                                                                                        |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fs/promises` | `readFile(path, "utf8"?)` (64 MiB), `writeFile` (8 MiB), `readdir(path, { withFileTypes }?)`, `exists`, `unlink`, `rmdir`, `mkdir(path, { recursive }?)`, `open(path, "r" \| "w" \| "a" \| "r+")` returning a `FileHandle` (`read(maxBytes?)`, `write`, `close`). Calls on one handle must be awaited in turn. |
| `process`     | `run(command, args?, { env?, cwd? })` returns `{ code, stdout, stderr }` (8 MiB per stream); `spawn(command, args?, options)` returns a `ChildProcess` (`pid`, `readLine`, `readErrLine`, `write`, `closeStdin`, `wait`, `kill`); `exit()`; `nextTick`; `platform`, `arch`.                                    |
| `net`         | `connect(host, port)` or `connect({ path })` returns a `Socket` (`read`, `write`, `close`).                                                                                                                                                                                                                    |
| `websocket`   | `WebSocket.connect(url, { headers? })` returns `{ read, write, close }`. Only `headers` is accepted; credential and control headers are refused.                                                                                                                                                               |
| `crypto`      | `createHash("md5" \| "sha1" \| "sha256" \| "sha512")`, `randomBytes(n ≤ 65536)`, `randomUUID()`.                                                                                                                                                                                                               |
| `buffer`      | `Buffer`: `from(value, encoding?)`, `alloc`, `isBuffer`, `byteLength`, `concat`, `toString(encoding?)`. Encodings: `utf8`, `hex`, `base64`, `base64url`, `latin1`.                                                                                                                                             |

A `ChildProcess` is the leader of its own process group. ## 12. Storage

- `localStorage` is a flat JSON object of string values in `<data dir>/localStorage.json`, shared by all of the plugin's runtimes. It needs `capabilities.storage` (granted by default). `flush()` resolves once the last change is on disk and retries a failed write.
- `sessionStorage` is per plugin and in memory until the shell exits.
- The data directory (`${dataDir}`) survives updates and removal of the plugin. Write files there with `fs.write = ["${dataDir}"]`.

## 13. Runtimes, loading and hot reload

- **One runtime per load.** Each widget load, panel load and the service runs in its own runtime, so module-level variables are not shared. Share state through `getState` / `setState`.
- **TypeScript.** `.ts` and `.mts` are type-stripped (strip-only mode, so line and column numbers stay correct). Enums, namespaces, parameter properties and decorators are refused.
- **Import resolution.** Extensionless `./util` tries `util.js`, then `util.ts`. `./a.b` tries `a.b.js` / `a.b.ts`. `./x.js` falls back to `./x.ts`. Imports cannot leave the plugin directory.
- **Hot reload.** Saving a `.js`, `.mjs`, `.ts` or `.mts` file in the plugin directory reloads the views and restarts the service. The directory is polled every 250 ms; `node_modules`, dot files and `*.d.ts` are skipped.
- **Listener cleanup.** Call the stop function an `onX` or `subscribe` returned when a view goes away. What happens to a listener whose view unloaded without that call is unverified.

## 14. Installing and running a plugin

- **Plugin sources** are listed in the shell config as `[[plugins.source]]` (`kind = "git"` or `"dev"`, `location`, `name`). A `dev` source points at a working directory and is the way to iterate on a plugin. Your own plugins also load from `~/.local/share/corona/plugins` (the `local` source).
- **Enable** a plugin by listing its id in `[plugins].enabled`, or in the settings app. The user approves its capabilities; the approval is stored under `[plugins.approved.<id>]`.
- **Show a widget** by adding it to a bar with `widget_type = "<id>:<name>"`.
- **User values** for settings are written to `[plugin_settings."<id>"]`.
- **Call the service** with `corona ipc plugin <id> <method> [json]`.
- **Types:** `corona types <plugin dir>` writes `corona.d.ts`.
- **Logs:** `console.*` output and unhandled rejections go to the corona shell process logs.

## Appendix: porting from API 1

API 1 ran on the vendored gpui-shell (QuickJS fork). The changes, in the order an author meets them:

1. **Manifest:** add `api = 2`. No key was renamed. `capabilities.corona` names are checked against the registry as the plugin loads; an unknown name fails the load.
2. **Import specifiers:** `"gpui"` and `"gpui-kit"` → `"corona/kit"`; `"gpui-base"` → `"corona/base"`; `"gpui-component"` → `"corona/component"`; `"gpui-fps"` → `"corona/fps"`. `"gpui-shell"` is gone: `Props`, `DialogOptions`, `ToastOptions` moved to `corona/kit`; `ElementBounds` is `Bounds`.
3. **Errors:** the per-module `type Error = { message }` and `T | Error` returns are gone. Functions throw or reject.
4. **Reads:** `x()` functions became `Signal<T>` values (still callable).
5. **Long-polls:** `nextCall`, `nextAction`, `nextChange`, `nextSleepEvent`, `nextRedirect`, and dbus `nextSignal` + `unsubscribe` became `onCall`, `onAction`, `onChange`, `onSleep`, `onRedirect` and `subscribe(rule, cb)`. Only `onCall` buffers; API 1 queued up to 16 changes or actions and 64 signals per subscription.
6. **Types:** `JsonValue` is `Value`. `NativeElement` and the ~130 `XxxElement` types became one `Element`. `Task`, `ScopePhase` (now `"render" | "event" | "task"`), `TaskOptions`, `transition()`, `spring()` and `MotionProperty` are gone. `corona.d.ts` replaces `gpui-kit.d.ts`.
7. **Context:** `cx.spawn` returns the body's result, not a `Task`, and takes no `{ owner }`. `cx.timer.*` handles only have `cancel()`.
8. **`window`:** `open_dialog`, `close_dialog`, `close_all_dialogs`, `close_sheet`, `remove_toast`, `clear_toasts` return `void`. `window.localStorage` / `sessionStorage` are no longer typed; use the globals.
9. **Events:** `local_position` and `bounds` are gone from mouse events; `position` is window-relative.
10. **Services:** the service's `cx` is reduced to `sleep` and `timer`.
11. **Runtimes:** every load has its own runtime (API 1: one per plugin).
12. **Stdlib:** global `crypto`, `atob`, `btoa` are removed; `setTimeout`/`setInterval` are new; the `tls` option of `fetch` and `websocket` is removed (no pinning); `Buffer`, `crypto` and `zlib` expose only the typed subset above.
13. **Storage:** `localStorage` moved from `store.json` to `localStorage.json` and nothing migrates it; renaming the file should carry values over (unverified). The size limits are gone.
14. **Images:** relative `image(path)` no longer resolves against the plugin directory; relative `svg(path)` reads built-in icons.
15. **Components:** `children([...])` needs an array; `Command` `on_select` / `on_confirm` take one object; `InputEvent` is `TextEvent`; `Select` gained `.value(id)`; `InputRange`, `InlineToken*` and `InputContent` moved to `corona/component`.
16. **TypeScript loading:** extensionless and dotted import resolution changed as in [13](#13-runtimes-loading-and-hot-reload).
